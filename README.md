# ZZZrdle

Wordle-style daily guessing game for [Zenless Zone Zero](https://zenless.hoyoverse.com/) characters.

## Play

**https://meetmonday.github.io/zzzrdle/**

## How to play

Guess the ZZZ agent in 5 tries. Each guess reveals 4 attributes:

- **Attribute** — element type (Fire, Ice, Electric, etc.)
- **Specialty** — role (Attack, Stun, Support, etc.)
- **Attack Type** — damage type (Slash, Strike, Pierce)
- **Faction** — character's organization

Green tile = correct match, grey = wrong.

## Game modes

| Mode | Description |
|------|-------------|
| **Daily** | One puzzle per day, same for everyone |
| **Streak** | Random characters, track your win streak |
| **Practice** | Unlimited guesses, no stats |

## Built with

- Vanilla HTML/CSS/JS — no frameworks, no build step
- Character data from [Zenless Zone Zero API](https://static.nanoka.cc/zzz/)
- Icons synced from [tgdm/zzzip](https://github.com/tgdm/zzzip) image pack (`data/fetch-icons.mjs`)
